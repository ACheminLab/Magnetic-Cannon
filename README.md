# Magnetic Cannon interactive model

Open `index.html` locally or publish this folder with GitHub Pages. The simulation has no build step and no external dependencies.

It can simulate a train of 1–10 rifles, animate the ball's position after a shot, plot the speed after each module, and export the data. The model uses the paper's measured magnetic-energy values at n = 0, 1, and 2, extends the screening trend smoothly for larger n, and estimates chain transmission with the experimental linear yield relation. This is an energy-level teaching model, not a time-resolved Hertz-contact solver.

Reference: A. Chemin et al., *American Journal of Physics* 85, 495 (2017). https://doi.org/10.1119/1.4979653
